# Notion Plus Workspace Tools

> Organize team knowledge, manage projects, build connected databases, and collaborate through a flexible workspace.

Notion Plus is a workspace plan for teams that need shared pages, structured databases, project tracking, and collaborative documentation. It combines writing, task organization, information management, and team coordination within a customizable environment.

The plan adds collaboration and workspace capabilities for growing projects, including expanded file uploads, extended page history, additional guests, custom forms, custom sites, charts, and selected integrations.
